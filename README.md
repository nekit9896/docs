# docs — документация по тестированию Гидроуклона (СДКУ «ЭВОСКАДА»)

Единая точка входа в документацию проекта автотестов `sdku_tests`.
Продукт: **Гидроуклон** (латиница `hydroslope`) — подсистема СДКУ «ЭВОСКАДА»
для контроля нефтепроводов. Написание «Гидроклон» — опечатка, не использовать.

**Если вы (человек или агент) пришли из другого репозитория — начинайте с этой страницы.**

## Карта репозитория

```
docs/
├── README.md                ← вы здесь: карта содержания
├── specs/                   ← дерево знаний (SDD), рабочая документация
│   ├── INDEX.md                 карта знаний + цикл поддержки + статусы перекладки
│   ├── knowledge/               фрагменты знаний (KB-*): домен, сервисы, шлюзы
│   ├── cases/                   сценарии тестов (1 кейс = 1 файл, HY-*)
│   └── trace/                   матрицы «кейс ↔ модуль репозитория», покрытие
├── confluence/              ← ИСТОЧНИК ИСТИНЫ (8 исходных; правки — только по команде владельца)
├── decisions/               ← журнал решений (договорённости, аудит)
├── meta/                    ← журналы расхождений и др.
├── plans/                   ← планы задач (мастер-документы)
└── .clinerules/             ← правила для агентов (одинаковы во всех репозиториях)
```

## Цикл поддержки документации

При изменении документации — impact-анализ по ID сущностей
(`specs/INDEX.md` → «Цикл поддержки»). Правила продублированы в
`.clinerules/00-docs-map.mdc` (одинаков для всех трёх репозиториев).

## Как пользоваться другим репозиториям (`hydro-backend-tests`, `sdku-test-tools`)

- Каждый репозиторий содержит `.clinerules/00-docs-map.mdc` — он ссылается на
  эту карту и на `specs/INDEX.md`.
- Перед задачами по архитектуре, контрактам, тест-планам — читать карту
  знаний `specs/INDEX.md` и соответствующие фрагменты; не изобретать факты.
- При расхождении документации и кода — сообщать владельцу, не замалчивать.

## Конвенции

- Формат — Markdown (`.md`), имена файлов — kebab-case.
- Секреты и реальные адреса стендов в документацию не включать
  (канонические URL — за переменной окружения/CI-переменной).
- Версии зависимостей смотреть в `pyproject.toml` / `poetry.lock`
  соответствующего репозитория.
