# Contract: CLI запуска прогонов

**Date**: 2026-11-18 | Контракт интерфейса запуска (FR-006, FR-009)

Интерфейс запуска автотестов для инженера и CI (pytest). Точка входа — корень пакета автотестов.

## Команды

| Цель | Команда |
|---|---|
| Полный прогон каталога | `pytest` |
| Набор HY-CALC | `pytest -m hy_calc` |
| Набор HY-HIST | `pytest -m hy_hist` |
| Набор HY-SYS | `pytest -m hy_sys` |
| Один кейс | `pytest tests/hy_calc/test_HY-CALC-012_*.py` |
| Группа кейсов | `pytest -k "HY-CALC-01"` |
| Повтор незавершённой части прогона | `pytest --last-failed` |
| Smoke-проверка стенда | `pytest -m smoke` |

## Параметры

- `--env <name>` — окружение из `config/env/<name>.yaml` (по умолчанию `test-stand`)
- `--junitxml=<path>` — JUnit XML отчёт (контракт с TestOps)
- `--report-json=<path>` — JSON-отчёт прогона (см. [report-schema.md](./report-schema.md))

## Коды выхода

| Код | Значение |
|---|---|
| 0 | все проверки пройдены (`passed`) |
| 1 | есть провалы поведения (`failed`) |
| 2 | ошибка конфигурации/окружения — прогон не стартовал |
| 3 | были только инфраструктурные ошибки (`infra_error`) без провалов поведения |

## Маркеры pytest

| Маркер | Назначение |
|---|---|
| `hy_calc` / `hy_hist` / `hy_sys` | наборы кейсов каталога |
| `smoke` | быстрая проверка доступности стенда |
| `slow` | кейсы с длительными окнами ожидания |
| `stand_depends` | требует восстановленного начального состояния стенда |

## Гарантии

- каждый запуск задействует только кейсы, привязанные к каталогу (FR-007)
- параллельный запуск на одном стенде блокируется с явным сообщением (FR-010)
