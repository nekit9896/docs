# HY-HIST-031 — Экспорт: пустой диапазон

**Требование:** R-HYDR-068
**Описание:** Оператор запрашивает экспорт за период, за который нет данных
(20:00–21:00, но сессия шла 08:00–08:10). Система возвращает HTTP 200 с CSV,
содержащим только заголовок (0 строк данных). Это **не ошибка** — оператор
просто запросил несуществующий период.

**Предусловие:**

- Сессия historical завершена (status = 8), период 08:00–08:10
- В `model_main_{id}` данные только за 08:00–08:10

**Действия:**

1. `api.export_(id, format="csv", startTime="2026-11-09T20:00:00Z", endTime="2026-11-09T21:00:00Z")` ⚠️ —
   система ищет данные → не находит → формирует пустой CSV
2. Проверить: HTTP 200, Content-Type: text/csv, тело = только заголовок
   `tag,timestamp,value,invalid` (без строк данных)

**Ожидаемый результат:**

| Шаг | Ожидание | Пояснение |
|---|---|---|
| 2 | HTTP 200, 1 строка (заголовок), 0 строк данных | Пустой диапазон |

_(Допущение 13: возвращаем 200 с пустым CSV, а не 404.)_
**Teardown:** `api.close(id)` ⚠️ → `RESET()`
